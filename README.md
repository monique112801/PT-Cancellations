# Physical Therapy Cancellations Analysis

## Overview
This project analyzes patient cancellation trends across physical therapy providers to identify changes over time and potential impacts on clinic operations.

## Tools Used
- Tableau
- Excel

## Skills Demonstrated
- Data Cleaning and Preparation  
- KPI Development  
- Data Visualization and Dashboard Design  
- Trend Analysis  
- Business Insight Generation  

## Key Insights
- Cancellations increased by 47% from 2024 to 2025  
- All therapists experienced higher cancellation volumes, with Therapist C contributing the most  
- Cancellation trends show consistent activity throughout the year, with peaks during mid-year months
